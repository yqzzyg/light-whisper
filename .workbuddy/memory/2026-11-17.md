
## 2026-11-17 UI 排查：窗口四周“底色”条
- 结论：不是渲染 bug。右侧/左侧 16px 浅灰条 = `--color-bg-primary #F5F6F7`（theme.css:11）+ `PADDING=16`（src/lib/constants.ts:1，MainPage.tsx:205 的 `padding: 12px 16px`）。
- 顶部看不出沟槽：title-bar 背景 `--color-bg-overlay rgba(245,246,247,.94)` 与页面底色同色。
- 左/下那圈 ~15px 深灰渐变是 DWM 窗口阴影（tauri.conf.json `transparent:true` + `decorations:false`），在客户区之外。
- 布局实现：.app-shell(flex, 100vw/100vh) > .app-sidebar(240px, #FFF) + .app-content(flex:1, pages.css:2873) → page-root > title-bar(32px) + results-area(padding 12/16, pages.css:74)。
- 改造：内容通栏。PADDING 16→0（用户先改的），新增 TITLEBAR_INSET=8 修掉 PADDING-8 变负值导致整条 padding 失效的问题；pages.css 末尾追加 .results-area .result-card / .settings-sections > .settings-card 圆角归零（避免贴边处漏出 #F5F6F7 缺口）。历史记录页仍保留自身 14px 内边距未动。校验：eslint / tsc / 912 单测全绿。
- 修正(11-17 晚)：那圈 8px "半透明边框" 的真正原因不是窗外阴影，而是 tao 的 MARKER_UNDECORATED_SHADOW：tauri.conf.json 主窗口 shadow 默认 true → with_undecorated_shadow(true) → WM_NCCALCSIZE 里把客户区四边各内缩 SM_CXSIZEFRAME+SM_CXPADDEDBORDER=8px（Win11 顶部再 +1px），webview 只填客户区，剩下的非客户区由 DWM 画阴影。唯一改动：主窗口加 "shadow": false。不需要 CSS，也不需要 DWM FFI。
