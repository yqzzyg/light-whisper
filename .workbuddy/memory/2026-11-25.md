## 说话人分离 P0 落地（笔记转写链路）

按 `docs/neo/speaker-diarization-plan.md` 实施完毕，端到端只剩「真实下载模型」没在干净机器验证。

### Python 侧（新增，均在 `src-tauri/resources/`）

- `speaker_segmentation.py`：pyannote-segmentation-3.0，10s 滑窗、powerset 7 类解码；
  `window_shift_seconds` 默认 **2.0**（1.0 太慢且无精度收益）。overlap 从**概率**算，不能投票。
- `speaker_embedding.py`：CAM++，80 维 fbank + **逐句均值归一化**（固定 CMVN 会把嵌入压平）。
- `speaker_diarize.py`：窗-说话人级嵌入 → 纯 numpy average-linkage 聚类（装入包不能依赖 sklearn）
  → 4 步后处理（phantom / 合并同人 / 坍塌检测 / 短段折叠）→ 相邻合并 → 长段切分。
  **关键坑**：每次后处理都要用 `_compact()` 同时重建 segments 与 centroids，
  否则簇 id 空间错位，真实说话人会被 fold 掉（第一次跑只剩 1 人的根因）。
- 阈值：`cluster_distance_cut=0.40`、`merge_centroid_cos=0.85`（openwhispr 的 0.5 会把两个人并成一个）。
- 实测：31 分钟真实录音 → 2 人 74.1%/25.7%、175 段、最长 57s（不超 Qwen3 的 115s）、
  **101 秒/小时**（基线 560）。批处理实测不可行，已放弃。

## 真实录音端到端验证（31 分钟，真实 ASR 非 mock）

用 `note-3-1795350200989.wav`（1868.01s，罗永浩《十字路口》一期）跑
`Qwen3ASRServer.transcribe_diarized`，真模型真推理：**107.2s 跑完**，
分离 46.8s + 175 次 ASR 59.9s，CUDA 后端，9346 字，判定 2 人。

- 说话人归属主体正确：主持人（罗永浩）问句/插话/广告口播与嘉宾长独白基本分对。
- **错误集中在段边界而非聚类**：一问一答被塞进同一 ASR 段（如 05:52
  「那你中学到他们学校了吗？我父母从来没教过我啊」），整段只能标一个人。
  约 10 几/175 段。怀疑 `adjacent_merge_gap_seconds=1.0` 把 1s 内快速插话
  合并进相邻大段，改进方向是降到 0.4~0.5 并保留帧级切换点。
- 开头 60 秒归属反了（片头音乐 + 开机闲聊，窗级嵌入被污染），2 个 turn。
- **环境坑**：本机没有现成的 3.10+ 且带 `soundfile`/`onnxruntime`/`kaldi-native-fbank`
  的环境。最终用 `conda env markitdown`(3.12) + pip 补装
  `soundfile`、`kaldi-native-fbank` 才跑起来；`hlwjg` 是 3.8，`r2t2_stream.py`
  的 `str | None` 注解会直接 SyntaxError，不能用它跑服务层。
